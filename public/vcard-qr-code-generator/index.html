What can a vCard QR code include?

Name, phone number, email address, website, company and other contact fields can be encoded into a standard vCard QR code.

Best uses

Add a vCard QR code to business cards, badges, resumes, event materials, storefront signs or email signatures.

Does it expire?

A static vCard QR code does not expire, although you must create a new one if the encoded contact information changes.
